What is a watermark?

A watermark is a semi-transparent mark placed over your photos or artwork to show ownership and discourage unauthorized reuse. It can be a logo, a brand name or a simple note such as a website or account handle.

How to use the watermark maker

Type your mark, then set its font, size, angle and opacity. A single watermark drops one mark on the canvas; the tiled mode repeats it across the image so no corner is unprotected. Lower opacity keeps your photo readable while still signing it.

Exporting

  • Copy CSS — apply the same mark and tiling to an image via CSS.
  • Export PNG — download a transparent watermark you can overlay in any editor.

When to use it

Use it for portfolio images, product photos, design drafts and anything you publish before the final sale or reveal.
