What is a QR code?

A QR code is a square barcode that links offline and online — scan it and a phone opens a URL, connects to Wi-Fi, saves contact details or shows plain text. It is the fastest way to bridge print and digital.

How to use the QR generator

Enter the content (URL, text or Wi-Fi details), then choose a style and color scheme so the code matches your brand instead of clashing with it. Add a label or a small logo in the center for a polished, identifiable code. Always test by scanning the result before printing or publishing.

Exporting

  • Export PNG — a crisp image for print and posters.
  • Export SVG — a scalable vector for large signage.

When to use it

Use it for packaging, business cards, flyers, menus, event tickets and any printed material that should lead straight to a web page.
