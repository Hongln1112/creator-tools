What is a color palette?

A palette is a small set of colors that work well together and are used consistently across a project. A good palette keeps an interface, brand or chart looking cohesive instead of accidental.

How to use the palette generator

Set a starting color, then choose a harmony rule — monochromatic, analogous, complementary or triadic — to automatically build colors that sit well together. Fine-tune individual swatches, lock the ones you like, and generate a new variation without losing your picks.

Exporting

  • Copy — grab the hex list or CSS variables in one click.
  • Export PNG — download a swatch sheet to share or reference.

When to use it

Use it to set up a new design, brand or data-viz project, or to rescue a site that has too many unrelated colors.
