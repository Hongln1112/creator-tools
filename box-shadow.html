What is a box shadow?

A box shadow is the soft or hard outline drawn behind an element, defined by offsets, blur, spread, color and an optional inset. It is the main way CSS creates elevation — the sense that a card sits above the page.

How to use the shadow generator

Drag the X and Y offsets to position the shadow, raise Blur to soften its edge, and use Spread to make it larger or tighter. Pick a color and add an inset shadow for a recessed look. The live preview on a real box lets you tune until the depth feels right.

Getting your shadow out

  • Copy CSS — paste the box-shadow value directly into your stylesheet.
  • Copy multiple — combine several shadows for layered depth.

When to use it

Use it for cards, buttons, modals and floating elements — anywhere you need UI to feel lifted, layered and intentional.
