What is a CSS gradient?

A CSS gradient is a smooth transition between two or more colors, drawn by the browser instead of an image file. Because it is pure CSS, it scales to any size without losing quality, loads instantly, and needs no extra image request. The four types on this page cover most real-world needs:

  • Linear — color flows along an angle you choose; ideal for page backgrounds and buttons.
  • Radial — color radiates from a center point, great for spotlight highlights and glows.
  • Conic — color sweeps around a point like a clock, used for pie accents and wheel effects.
  • Mesh — several soft color blobs blend into one another for a rich, painterly look.

How to use the generator

Pick a type, then set the angle (for linear and conic) or the blob density (for mesh). Click a color swatch to change a stop, drag its Position to spread the transition, and lower Opacity to soften it. Add up to six stops, or tap Shuffle for an instant palette. The live preview updates as you go. Finally, choose an aspect ratio to match your target — 16:9 for banners, 3:4 for posts, 9:16 for stories.

Getting your gradient out

  • Copy CSS — paste the background: value straight into a stylesheet.
  • Copy CSS variable — save it as a --gradient token you can reuse across components.
  • Export PNG — download a wide, high-resolution image when you need a file rather than code.

Your last settings are remembered in your browser, so you can close the tab and come back to keep working.

When to use gradients

Gradients are a fast way to add depth and brand color without image assets — as page or section backgrounds, button fills, card accents, hero overlays and social cover art. Since they are CSS, they stay crisp at any resolution and can be animated with transitions.
